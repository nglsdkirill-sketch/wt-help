# WT Шпаргалка: сборка APK

Справочник по War Thunder в виде Android-приложения (Android 8.0 и новее).
Собирается автоматически на GitHub, ничего ставить на компьютер не нужно.

## Как получить .apk

1. Зайди на github.com и создай новый репозиторий (кнопка New). Название любое, например `wt-guide`.
2. Распакуй этот архив. В репозитории нажми **Add file → Upload files** и перетащи
   внутрь все файлы и папки из распакованной папки, кроме папки `.github`
   (она скрытая, при перетаскивании часто теряется). Нажми **Commit changes**.
3. Папку `.github` добавь вручную: **Add file → Create new file**, в поле имени
   впиши `.github/workflows/build.yml` (слэши создадут папки), вставь туда
   содержимое файла `.github/workflows/build.yml` из архива и нажми **Commit changes**.
4. Открой вкладку **Actions**. Сборка запустится сама после коммита
   (если нет: Build APK → Run workflow). Она идёт 3–6 минут.
5. Когда рядом с запуском появится зелёная галочка, открой его и внизу
   в разделе **Artifacts** скачай `WT-Guide-apk`. Внутри zip лежит `app-debug.apk`.
6. Перекинь `app-debug.apk` на телефон и открой его. Android спросит разрешение
   на установку из неизвестных источников: разреши для того приложения,
   откуда открываешь файл (Файлы или браузер).

## Если сборка упала

Красный крестик в Actions: открой запуск, нажми на шаг, который упал, и пришли
текст ошибки. Обычно это одна строка в конце лога.

## Что внутри

- `app/src/main/assets/index.html` : сам справочник (советы, позиции, снаряды, калькулятор).
- `app/src/main/java/.../MainActivity.java` : окно приложения (WebView).
- `.github/workflows/build.yml` : сборка APK на GitHub.

Приложение подписано отладочным ключом: для личной установки этого достаточно,
для публикации в магазине понадобится свой ключ.
